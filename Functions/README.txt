PYTHON FUNCTIONS - FIRST 20 PROGRAMS

These are simple, separate Python files based on programs 1-20 in the uploaded
functions document.

How to use:
1. Extract this ZIP file.
2. Open the folder in VS Code.
3. Open any .py file and click Run Python File.
4. Enter the requested input in the terminal.

Notes:
- Program 18 uses example grade boundaries: A >= 90, B >= 75, C >= 60,
  D >= 40, otherwise F. Change them if your teacher specifies other rules.
- Program 19 uses example electricity slabs: first 100 units Rs. 3/unit,
  next 100 Rs. 5/unit, and above 200 Rs. 7/unit. Actual slabs vary by provider.
