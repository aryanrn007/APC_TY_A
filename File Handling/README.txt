FIRST 10 PYTHON FILE-HANDLING PROGRAMS

These programs correspond to questions 1–10 in the uploaded file-handling PDF.

How to run:
1. Extract this ZIP file.
2. Open a terminal or command prompt in the extracted folder.
3. Run a program with: python 01_create_student_file.py
4. For programs 2–10, enter the name/path of a text file when prompted.
   You can first run program 1 to create student.txt.

Notes:
- Program 1 creates/overwrites student.txt.
- Program 3 appends to an existing file.
- Program 7 counts all characters read, including spaces and newline characters.
- Program 10 counts tabs/newlines as whitespace, not as special characters.
